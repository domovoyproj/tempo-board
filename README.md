# Темпо

Личный планировщик с приоритетами, поиском и таймером сосредоточенной работы. Светлый интерфейс, спокойная типографика и один список для дел, которые сейчас важны.

## Возможности

- Создание, редактирование и завершение задач; дата, приоритет и заметка.
- Просроченные задачи остаются в плане на сегодня. Завершённые доступны отдельно.
- Поиск по названию и заметке, фильтрация по приоритету.
- Фокус-сессии на 15, 25 и 50 минут с паузой и сбросом.
- Сохранение задач в браузере, экспорт и проверяемый импорт JSON.
- Адаптивный интерфейс, управление с клавиатуры, поддержка уменьшенного движения.

## Запуск

Нужен Node.js 20 или новее. Сторонних пакетов нет.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Другой порт задаётся переменной окружения PORT.

```sh
npm test
```

Для статического хостинга достаточно содержимого dist/. Используйте HTTP-сервер: ES-модули не рассчитаны на открытие через file://.

## Данные и ограничения

Задачи хранятся в localStorage текущего браузера. Между устройствами синхронизации нет. Экспортируйте JSON перед очисткой данных браузера. Импорт заменяет текущее состояние после подтверждения. Данные не отправляются на сервер.

Таймер работает, пока открыта страница; закрытие или перезагрузка сбрасывает сессию. Скрытие вкладки не сбивает отсчёт: оставшееся время вычисляется по абсолютной отметке. Автоматических уведомлений вне вкладки нет.

## Устройство

- dist/app.js — интерфейс и события.
- dist/model.js — выборка задач, прогресс и валидация резервных копий.
- dist/shared.js — даты, безопасный вывод текста и локальное сохранение.
- tests/ — проверки фильтров, дат и прогресса.
- server.mjs — локальный сервер на стандартных модулях Node.js.
